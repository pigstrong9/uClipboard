# uClipboard M2 增量验收：自动粘贴 / Alt+V / 托盘

- 日期：2026-11-20
- 分支：`feat/m1-core`（M2 粘贴增量也在此分支）
- 环境：Windows 11、Rust 1.100、Tauri 2.12、enigo 0.6.1
- 结论：**通过**（Windows 真机）

## 实现

- 双击条目或按 `Enter`：写回剪贴板 → 隐藏主窗口 → 等待 200ms → enigo 发送 `Ctrl+V`；macOS 使用 `Cmd+V`
- `Ctrl/Cmd+C` 仍为仅复制，不隐藏窗口
- 全局快捷键 `Alt+V`：切换显示/隐藏主窗口；最小化时按 `Alt+V` 恢复并聚焦；主窗口不显示任务栏图标
- 系统托盘：左键显示主窗口；右键菜单提供「显示主窗口」「退出」
- 中转窗口内双击卡片：优先把焦点还给目标应用并粘贴，中转窗口保持可见；失败时降级为隐藏/重开
- 自动粘贴失败时：重新显示窗口并把错误返回给前端 toast

## 验证

使用一个 WinForms 测试窗口（文本框内容变化时写入文件）作为粘贴目标：

1. 聚焦测试窗口 → 唤起 uClipboard → 双击 `M1 test alpha`
2. 测试窗口文本变为 `M1 test alpha 2026-11-20` → 自动粘贴成功
3. 粘贴后 `GetForegroundWindow` 为测试窗口句柄 → 剪贴板窗口已隐藏、焦点已返回
4. 按 `Alt+V` 后 `GetForegroundWindow` 变为 uClipboard 主窗口句柄 → 快捷键唤回成功
5. SQLite 中该条 `copy_count` 增加，说明使用了「使用即置顶」逻辑

说明：Tauri 隐藏窗口后，WebView 的 `document.visibilityState` 仍可能显示 visible，不能作为判断依据；验收以目标窗口实际收到内容 + 前台窗口句柄为准。

## 已知限制

- macOS 需要「辅助功能」授权，Wayland 下模拟粘贴可能失败（失败会重新显示窗口并提示）
- 目标应用若以管理员权限运行，普通权限的本应用可能无法向其发送按键（Windows UIPI）
- 托盘图标在 Windows 11 可能位于任务栏溢出区；用 `Alt+V` 更可靠
- 托盘菜单目前只有「显示主窗口」「退出」；暂停监控、清空历史等随 M3 设置页补齐
- 双击粘贴后没有成功 toast（窗口已隐藏）；失败时会重新显示窗口并提示
