# uClipboard M2 增量验收：多选与独立临时中转窗口

- 日期：2026-11-20
- 分支：`feat/m1-core`
- 环境：Windows 11、Tauri 2.12、WebView2 157
- 结论：**通过**（Windows 真机）

## 实现

- 主列表单击条目切换高亮/多选，无需 Shift；右栏按钮显示已选数量
- 点击右栏「多选 / 临时中转」：创建独立的 Tauri `WebviewWindow`（label `transfer`），不是主窗口内的面板
- 中转窗口：300×380、无边框、透明圆角、置顶、跳过任务栏；默认放在主窗口右侧，空间不足时放左侧并夹取到屏幕内
- 标题栏：固定、复制全部、收藏全部、搜索、关闭；条目为与主列表同款卡片，来源显示「临时中转」
- 关闭中转窗只隐藏并清空中转列表，不退出应用；再次点击主窗口按钮可重开
- 合并复制：多条文本按换行合并；多个文件合并为文件列表；文本+文件可同时写入剪贴板
- 搜索按图标展开；收藏全部为统一收藏/取消收藏
- **双击中转卡片直接粘贴到目标应用**：打开剪贴板时通过 Alt+V 记录目标窗口句柄；双击时优先把焦点还给目标窗口并发送 Ctrl+V，中转窗口保持可见、无隐藏/重开闪烁；目标窗口失效、提权拦截或未记录目标时自动回退到隐藏/重开方案
- 主窗口不显示任务栏图标；`Alt+V` 切换显示/隐藏，最小化时也会恢复并聚焦

## 验证

| 场景 | 结果 |
|---|---|
| 主列表选中 2 条 TEXT | `picked=2`，右栏徽标 2 |
| 打开中转窗口 | 出现独立置顶窗口，CSS 卡片 2 张，首卡高亮 |
| 合并复制 | 系统剪贴板读出两行文本，toast「已复制 2 条」 |
| 使用即置顶 | 两条 `copy_count` 各 +1 |
| 去重抑制 | 合并后的文本没有作为新记录重复入库 |
| 收藏全部 | 两条 `favorite=1`，toast「已收藏」 |
| 搜索过滤 | 输入 `ONE` 仅 1 张卡片，清空恢复 2 张 |
| 关闭 | `FindWindow` 对应窗口不可见，中转列表清空 |
| 重开 | 主窗口选择仍保留，中转窗重新显示 2 张卡片 |
| 双击中转卡片 | 目标输入框收到对应文本，剪贴板同步更新，中转窗仍显示 2 张卡片，且未隐藏/重开（日志确认 target focus） |
| 双击后主窗口 | 快速路径保持可见；若目标窗口失效走降级路径，主窗会临时隐藏，按 `Alt+V` 可恢复 |
| 任务栏图标 | 主窗口与中转窗均跳过任务栏；应用仍可通过 `Alt+V` / 托盘恢复 |
| 窗口位置 | 主窗口可见时能正常定位；启动时显式显示主窗口，避免隐藏状态下算到屏幕外 |

调试笔记：Tauri 同步命令中创建 `WebviewWindow` 会与主线程互锁，`open_transfer` 已改为 `async` 命令；窗口入口使用独立 `transfer.html` 多页面入口，避免 `index.html?window=transfer` 解析成 `about:blank`。

## 已知限制

- 多条合并复制遇到图片会返回错误提示，暂不支持多条图片合并
- 多选图片 + 其他类型暂不支持合并；单条复制仍正常
- 中转窗口不提供逐条移除/拖拽排序，关闭即清空
- macOS/Wayland 未实测
- 设置页仍未接入，因此中转窗口尺寸/固定状态暂不可配置
