## 运行方式

```bash
node prototypes/serve.js
```

打开 http://localhost:4173 。

原型支持以下查询参数，便于截图与评审：

- `?theme=light` / `?theme=dark`：指定主题
- `?tab=favorite` / `?tab=text` / `?tab=image` / `?tab=files`：指定分类
- `?settings=1`：直接打开设置页

刷新页面会恢复 mock 数据（原型不做持久化）。

## 视觉对照结论

已对齐参考图的主要元素：

- 头部：`剪贴板` 标签、宽搜索框、右侧工具图标
- 分类行与激活态、收藏计数
- 文本 4 行截断与展开、图片缩略图与尺寸、文件列表与数量
- 相对时间、字符数/尺寸/文件数、右侧序号
- 选中蓝色描边、悬停反馈
- 右侧蓝色圆形快捷按钮、右下角悬浮图标、左下角状态标签
- 亮/暗双主题与冷蓝主色 `#368CFF`

与 uTools 原版仍存在的差异（有意为之）：

- 图标为 Lucide 风格自绘 SVG，不使用 uTools 美术素材
- 右侧快捷按钮为「复制/粘贴/置顶」，未实现合并复制
- 右下角为「设置/清空」两个图标
- 无紧凑悬浮面板、无多选、无拖拽（v1 非目标）
- 字体渲染与 DPI 会随系统略有差异
