## 运行方式

```bash
node prototypes/serve.js
```

打开 http://localhost:4173 。

原型支持以下查询参数，便于截图与评审：

- `?theme=light` / `?theme=dark`：指定主题
- `?tab=favorite` / `?tab=text` / `?tab=image` / `?tab=files`：指定分类
- `?settings=1`：直接打开设置页

刷新页面会恢复 mock 数据（原型不做持久化）。

## 最终视觉与合规清理

按用户反馈收敛为简约风格，同时保留合规清理：

- 左上角仅保留「剪贴板」三个字，不再显示英文品牌与标签
- 主色为克制的蓝色：亮色 `#3B82F6`、暗色 `#60A5FA`
- 仅「收藏」Tab 显示数量，其他分类保持简洁
- 条目恢复为纯文本/图片/文件卡片，无类型徽标、无左侧色条
- 右侧改为独立按钮栏（复制/粘贴/置顶三个圆形按钮），滚动条位于列表右缘、按钮栏左侧
- 按钮栏底部为设置与清空历史；左下角保留简洁状态标签
- mock 数据已匿名化：示例路径、通用内容，不含个人路径、内部文档名或第三方代码
- 文档已中性化；新增 Apache-2.0 `LICENSE`、`NOTICE` 与 `README.md`

## 视觉对照结论

保留通用剪贴板管理器的熟悉结构：

- 头部：左上角「剪贴板」、宽搜索框、右侧工具图标
- 分类行、搜索、列表与条目的基本组织方式
- 文本 4 行截断与展开、图片缩略图与尺寸、文件列表与数量
- 相对时间、字符数/尺寸/文件数、右侧序号
- 选中描边、悬停反馈
- 右侧独立按钮栏、按钮栏底部工具按钮、左下角状态标签
- 滚动条位于列表右缘、按钮栏左侧
- 多选单击高亮与右下角「临时中转」浮窗
- 亮/暗双主题

已通过最终收敛形成清爽的简约风格，不依赖任何第三方美术素材。

「临时中转」在 M0 原型中是应用内浮层；Tauri 版将实现为独立置顶小窗，位置贴近主窗口右下角。

与参考产品仍存在的功能差异（有意为之）：

- 右侧快捷按钮为「复制/粘贴/置顶」，未实现合并复制
- 右下角为「设置/清空」两个按钮
- 无紧凑悬浮面板、无多选、无拖拽（v1 非目标）
- 字体渲染与 DPI 会随系统略有差异
