## 运行方式

```bash
node prototypes/serve.js
```

打开 http://localhost:4173 。

原型支持以下查询参数，便于截图与评审：

- `?theme=light` / `?theme=dark`：指定主题
- `?tab=favorite` / `?tab=text` / `?tab=image` / `?tab=files`：指定分类
- `?settings=1`：直接打开设置页

刷新页面会恢复 mock 数据（原型不做持久化）。

## 合规差异化 pass

在保持通用剪贴板布局与操作习惯的前提下，做了以下区分：

- 主色改为靛蓝 `#5B6CFF` + 青色 `#22D3EE` 渐变，替代参考产品的纯蓝
- 自有双叠层 Logo；品牌区为 `uClipboard + 剪贴板` 标签
- 分类 Tab 全部显示数量，激活态为靛蓝浅底胶囊
- 条目增加类型徽标与左侧色条：文本靛蓝、图像青色、文件绿色
- 右侧快捷按钮改为圆角方形渐变按钮组，并加容器底衬
- 右下角工具按钮与左下角带状态点的状态标签为自有设计
- mock 数据已匿名化：示例路径、通用内容，不含个人路径、内部文档名或第三方代码
- 文档已中性化；新增 Apache-2.0 `LICENSE`、`NOTICE` 与 `README.md`

## 视觉对照结论

保留通用剪贴板管理器的熟悉结构：

- 头部：品牌区、宽搜索框、右侧工具图标
- 分类行、搜索、列表与条目的基本组织方式
- 文本 4 行截断与展开、图片缩略图与尺寸、文件列表与数量
- 相对时间、字符数/尺寸/文件数、右侧序号
- 选中描边、悬停反馈
- 右侧快捷操作、右下角工具按钮、左下角状态标签
- 亮/暗双主题

已通过上述差异化 pass 形成自有识别度，不依赖任何第三方美术素材。

与参考产品仍存在的功能差异（有意为之）：

- 右侧快捷按钮为「复制/粘贴/置顶」，未实现合并复制
- 右下角为「设置/清空」两个按钮
- 无紧凑悬浮面板、无多选、无拖拽（v1 非目标）
- 字体渲染与 DPI 会随系统略有差异
