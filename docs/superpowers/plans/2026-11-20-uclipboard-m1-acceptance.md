## 真机验证

通过真实 Tauri 窗口 + Windows 剪贴板 + SQLite 查询验证：

| 场景 | 结果 |
|---|---|
| 复制文本 | 入库，`kind=text`，预览与字符数正确 |
| 复制文件（`win.ini`） | 入库，`kind=files`，内容为路径 JSON，文件数正确 |
| 复制图片 | 入库，`kind=image`，原图与 `_thumb.jpg` 落盘，列表中显示缩略图 |
| 重复复制已有内容 | 行数不变，`copy_count +1`，移动到非置顶列表顶部 |
| 搜索 `beta` | 仅剩 1 条匹配 |
| 行内复制 | 系统剪贴板读回 `M1 test beta 2026-11-20` |
| 收藏 | SQLite `favorite=1`，收藏 Tab 计数变为 1 |
| 置顶 | SQLite `pinned=1`，列表显示置顶徽标并排在最前 |
| 删除 | 搜索结果 1→0，总数 5→4 |
| 图片预览 | 弹窗加载原始 PNG data URL，尺寸正确 |
| 主题切换 | `data-theme` 从 dark 切到 light |
| 重启应用 | 4 条记录从 SQLite 恢复，置顶/收藏状态保留 |

验证方法：WebView2 远程调试（`--remote-debugging-port=9222`）执行页面脚本，配合 PowerShell `Set-Clipboard` / `Get-Clipboard` 与 `node:sqlite` 读取数据库。未提交任何界面截图，避免包含本机剪贴板中的私人图片。
